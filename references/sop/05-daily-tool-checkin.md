# 05 每日工具使用与双表打卡

- task_id：`daily_tool_checkin`
- 优先级：P0
- 执行人：7 位采销全员
- 流程负责人：赵六、张三
- 排期：每天 11:00
- 依赖：浏览器、OSW 登录态、JoySpace 登录态

## 执行步骤

1. 打开本人已登录的采销工作台：<https://osw.jd.com/home>。
2. 分别进入 POP 端和京喜端首页，在右侧「有问题找 AI 助手」→「大家都在问」中，各点击一个当天可见的咨询类问题。
3. 确保**实际发起提问**，并核实助手已回答。只提问，不提交助手生成的商品维护等额外操作。
4. 两端提问成功后，打开表格：<https://joyspace.jd.com/table/PAasp0HBU0cOSEDXLw70>。
5. 在「全员需做」和「自营采销」两个 sheet 中，找到【本人姓名】列及当天日期对应的单元格。
6. 通过网页点击单元格，在「已完成 / 未完成」下拉中选择「已完成」，确认保存成功。
7. 如果当天日期不存在：先确认表内确实没有该日期，再优先在日期空白行填写当天日期；没有空白行时新增一条记录，然后把本人当天状态选为「已完成」。
8. 不重复新增日期，不修改其他同事或其他日期的状态。
9. 已有「已完成」时不要重复点击，以免取消选中。

## 完成判定

四项全部满足才可 `done`：

1. POP 端提问成功且有回答；
2. 京喜端提问成功且有回答；
3. 「全员需做」本人当天为已完成；
4. 「自营采销」本人当天为已完成。

登录失效、提问失败、表格无法保存时如实 `fail`，禁止虚假打卡。

## 完成留痕

```powershell
python scripts/jx_task.py done --task daily_tool_checkin `
  --summary "POP/京喜两端提问已回答，全员需做+自营采销双表已打卡" `
  --metric POP提问=成功 --metric 京喜提问=成功 --metric 全员需做=已完成 --metric 自营采销=已完成 `
  --url "https://joyspace.jd.com/table/PAasp0HBU0cOSEDXLw70"
```

重试时跳过已成功步骤；已有「已完成」不重复点击。

## 现状

PDF 只给出作业名称和负责人，没有独立操作细则。可复用的规则在 `04-tejia-weekly.md` 的「后续 5.9减5 / 4.9减4 券池」：

```
【建议价 − 2.5 − 成本 − 快递费】≥ 0
【建议价 − 2 − 成本 − 快递费】≥ 0
```

两条都 ≥0 才允许报名；建议价取活动池的报名价上限，成本=采购价，快递费=单均物流（一般 2 元/单）。

## 执行前必须确认

1. 本期活动 ID、area、batchId、场次时间；不得跨期复用。
2. 是否与特价共用前置池（`area=38801203` / `activity=101766465`）和商品档过滤规则。
3. 平台禁令、外投清单、东东农场例外是否与特价一致。
4. 提交后回查接口与失败明细下载方式。

确认后在 `data/tasks.json` 把 `status` 改为 `ready`，并把 `auto` 改为 `true`。

## 禁止

- 不得跳过「与本人商品档取交」。
- 不得只满足一条公式就报名。
